External Display Tools

RTSS, EasyBluetoothExportHelper, and Xbox Game Bar

EasyBluetooth can display visible device batteries outside the main window: directly in RTSS for games, through the open-source EasyBluetoothExportHelper for AIDA64 SensorPanel and RTSS Overlay Editor, and inside Xbox Game Bar with the EasyBluetooth Battery widget.

AIDA64 and Game Bar require the Unified Standard Data API to be enabled first. Free users can display the first visible device. VIP users can export all visible devices. 2.4G add-on restrictions still apply to restricted receiver groups.

RTSS In-Game OSD

Install and run RTSS, then enable RTSS OSD in EasyBluetooth's Game OSD / AIDA64 Export settings.

EasyBluetoothExportHelper

Download the helper from GitHub Releases. It reads the local Unified Standard Data API and writes AIDA64 ImportValues.

Xbox Game Bar Widget

Enable the Unified Standard Data API, keep EasyBluetooth running, press Win + G, and add the EasyBluetooth Battery widget from the Xbox Game Bar widget store.
